# Картинки редизайна

Сюда кладём макеты для новой версии сайта (ветка redesign).
Старая папка `../images/` относится к действующему сайту — её не трогаем.

- `home/`     — кадры ленты на главной
- `realdeal/` — кадры кейса RealDeal
- `logo/`     — знаки (X.svg — квадрат, «X 2.svg» — вордмарк)

Экспорт из Figma: PNG, 2x, кроп по содержимому. Имена не менять.

## Что лежит рядом с каждым PNG
- `имя.png`          — оригинал из Figma, запасной вариант для <img>
- `имя.webp`         — тот же размер, WebP БЕЗ потерь (видимые пиксели
                       совпадают с PNG один в один), отдаётся по srcset
                       как самый крупный вариант
- `960/имя.webp`,
  `1920/имя.webp`    — те же макеты, уменьшенные, тоже без потерь;
                       браузер берёт по ширине экрана и плотности.
                       Есть не у всех: если уменьшенный файл не легче
                       оригинала хотя бы на 30%, его не делаем.

Менять один файл — значит пересобрать все его варианты.
